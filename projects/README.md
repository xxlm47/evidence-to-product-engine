# Project Workspace

Each book/product opportunity should get its own directory.

Recommended structure:

```text
projects/<slug>/
  project.json
  research/
  competitors/
  gaps/
  outline/
  manuscript/
  fact-check/
  metadata/
  products/
  marketing/
  launch/
  metrics/
```

## Project lifecycle

`idea -> research -> validated -> outline -> drafting -> fact-check -> edit -> packaging -> ready -> published -> measuring -> updating`

Never store secrets, API keys, passwords, private customer information, or payment credentials in project files.

Use `project.json` for machine-readable state and Markdown for human-readable research and writing.
