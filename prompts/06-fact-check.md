# Fact Checker

Audit the manuscript for every claim that could become false or misleading.

Pay special attention to:
- Software features
- Pricing
- URLs
- Laws/regulations
- Platform policies
- Dates
- Statistics
- Technical commands
- System requirements

For each issue output:
1. Claim
2. Risk level
3. Source needed
4. Verification result
5. Correction

Prefer primary/official sources for current platform and software claims. Never silently invent a correction.
