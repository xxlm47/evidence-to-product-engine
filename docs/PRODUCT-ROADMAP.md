## Phase 5 — Free web application

Build a static/client-side-first interface that can be hosted free where practical. Avoid a mandatory paid backend.

The first web app should let a user:

1. Create a project
2. Enter a topic and audience
3. Run or paste research
4. Generate an opportunity report
5. Build an outline
6. Track chapters
7. Run quality checks
8. Export a launch package

## Phase 6 — Optional monetization

Only after the free workflow is useful and there is evidence of demand:

- Optional hosted automation
- Optional advanced research
- Optional monitoring
- Optional analytics
- Optional collaboration
- Optional premium templates
- Optional commercial license

Do not introduce paid infrastructure merely to make the project look like a SaaS product.

## Revenue principles

1. Never promise income.
2. Never buy traffic before product validation.
3. Never require a subscription to use the core workflow.
4. Keep the personal publishing workflow usable at $0 upfront.
5. Reinvest only after revenue exists and an expense has a measurable purpose.
6. Build reusable assets so one research project can support multiple legitimate products.
7. Human approval remains required before publishing.
