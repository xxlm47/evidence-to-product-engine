# Competitor + Gap Analysis

Analyze competing books/products without copying them.

For each competitor capture:
- Audience
- Promise
- Scope
- Structure
- Price if publicly visible
- Freshness
- Strengths
- Weaknesses
- Repeated reader complaints

Then identify gaps such as:
- Missing audience
- Missing workflow
- Outdated instructions
- Poor beginner explanation
- Missing troubleshooting
- Missing examples
- Missing templates/checklists

A gap must be supported by evidence. Do not manufacture complaints or claim a gap exists merely because you want differentiation.
